Python File and Data Handling - Practice Notes

  SECTION 1: WHAT FILES ARE
  A file is just text stored on your computer.
  Python reads a file line by line, from top to bottom.
  Every line from a file ends with an invisible newline character.

  SECTION 2: OPENING FILES
  You open a file with the open function.
  The with keyword closes the file for you automatically.
  Always let Python close the file so nothing gets corrupted.

SECTION 3: CLEANING TEXT
  The strip method removes whitespace from both ends of a line.
  The lower method makes text lowercase for easy matching.
  The replace method swaps one piece of text for another.
  Cleaning data is most of the work in real automation.

  SECTION 4: COLLECTIONS
  A list holds many items in order, looked up by position.
  A dictionary holds labeled values, looked up by name.
  Use append to add an item to the end of a list.
  Use a dictionary to count how many times something appears

  SECTION 5: LOGIC AND LOOPS
  A for loop repeats an action for every item.
  An if statement makes a decision based on a condition.
  An else block runs when the if condition is false.
  The word in checks whether text appears inside other text.

  SECTION 6: FINDING FILES
  The pathlib tool lets Python discover files on disk.
  The glob method finds files matching a pattern.
  The star symbol is a wildcard meaning anything.
  Use rglob to search through every subfolder too.
